# Test Results

Store measured semi-final evidence here.

Suggested files:
- crash-tests.csv
- helmet-worn-tests.csv
- sms-tests.csv
- pothole-tests.csv
- wet-road-tests.csv
- screenshots/
- demo-notes.md

## Minimum useful columns

### Crash tests
`trial,event_type,detected,countdown_started,cancelled,event_score,notes`

### SMS tests
`trial,gps_valid,sms_success,delivery_seconds,controller_reset,notes`

### Vision tests
Use actual ground-truth labels and model outputs.

**Do not add invented numbers.**
